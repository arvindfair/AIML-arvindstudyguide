You learnt that the transformer model initially used a single attention head to manage the query (Q), key (K) and value (V) matrices. In this approach, all the attention calculations are handled by one head, which processes the entire output dimension Equation. However, researchers found that this approach could be improved by introducing multiple attention heads.


In the multi-head attention mechanism:

Multiple attention heads are used instead of just one, allowing the model to gather diverse perspectives on the input.
Each attention head independently manages its own set of Q, K and V matrices, distributing the output dimension (Equation) across the heads and reducing the workload for each individual head. 
Each attention head maintains its own set of weights - Equation, each of size Equation, in which Equation is the input dimension, and Equation is the reduced output dimension per head. 
The Q, K and V tuples generated by each head are then concatenated, and a projection matrix is applied to transform the concatenated result into the final output space, producing the desired Equation representation.
 

For example, with Equation = 5, Equation = 4, Equation = 8 and Equation = 4, each head generates a 2-dimensional output (Equation).

 

These outputs are concatenated to form a 5 x 8 matrix, which is then projected to maintain the same output size.


This multi-head attention mechanism enhances the model's ability to capture different aspects of the input, resulting in richer and more diverse representations, which is crucial for tasks such as natural language processing.

The core intuition of **Multi-Head Attention** comes down to solving a fundamental problem: **one attention head can only focus on one type of relationship at a time.**

If a sentence says:

> *"The bank by the river refused the loan because it was bankrupt."*

* Word *"bank"* has a **geographical context** (*river*).
* Word *"bank"* has a **financial context** (*loan, bankrupt*).
* Word *"it"* has a **grammatical coreference** (*which noun does "it" refer to?*).

If you have only one attention head, it has to average all these relationships together into a single set of attention weights. By using **multiple heads**, each head operates in a "parallel world" focusing on a different perspective (e.g., Head 1 tracks grammar, Head 2 tracks semantic meaning, Head 3 tracks positional distance).

---

## The "Clever Trick": No Extra Computation

A common point of confusion is thinking that 4 heads take 4 times more work or output 4 times more numbers. **They don't.**

Instead of computing one large $8$-dimensional output, the job is split:


$$\text{Head Dimension } (D_3) = \frac{\text{Desired Model Dimension } (D_2)}{\text{Number of Heads } (H)}$$

Using the lecture numbers:

* Total tokens: $N = 5$
* Initial token dimension: $D_1 = 4$
* Desired final dimension: $D_2 = 8$
* Number of heads: $H = 4$

$$\text{Dimension per head } (D_3) = \frac{8}{4} = 2$$

Each head only produces a **$2$-dimensional** slice. When all 4 heads finish, their slices are glued side-by-side ($2 + 2 + 2 + 2 = 8$), returning right back to the original target dimension of $8$.

---

## Step-by-Step Breakdown

### 1. Independent Weight Projections

Instead of one set of large matrices ($W_Q, W_K, W_V \in \mathbb{R}^{4 \times 8}$), each head $i$ gets its own smaller, specialized set of weights:

$$W_{Q}^{(i)}, W_{K}^{(i)}, W_{V}^{(i)} \in \mathbb{R}^{4 \times 2} \quad (\text{for } i = 1, 2, 3, 4)$$

For each head $i$:


$$Q_i = X W_{Q}^{(i)} \quad (5 \times 2)$$

$$K_i = X W_{K}^{(i)} \quad (5 \times 2)$$

$$V_i = X W_{V}^{(i)} \quad (5 \times 2)$$

---

### 2. Parallel Attention Computations

Each head runs self-attention completely independently:

$$\text{Head}_i = \text{softmax}\left(Q_i K_i^T\right) V_i$$

Dimensional trace for Head $i$:

* $Q_i K_i^T$: $(5 \times 2) \times (2 \times 5) = (5 \times 5)$ attention score matrix.
* $\text{softmax}(Q_i K_i^T) \times V_i$: $(5 \times 5) \times (5 \times 2) = \mathbf{(5 \times 2)}$.

Every head outputs an independent summary of size **$5 \times 2$**.

---

### 3. Concatenation (Putting Heads Together)

The outputs of all $4$ heads are stacked column-wise:

$$\text{Concat}(\text{Head}_1, \text{Head}_2, \text{Head}_3, \text{Head}_4) = \begin{bmatrix} \text{Head}_1 & \text{Head}_2 & \text{Head}_3 & \text{Head}_4 \end{bmatrix}$$

$$\text{Shape: } [5 \times 2] \ \Vert \ [5 \times 2] \ \Vert \ [5 \times 2] \ \Vert \ [5 \times 2] = \mathbf{5 \times 8}$$

---

### 4. Output Projection Matrix ($W_O$)

Concatenation simply glues the columns together; the heads haven't communicated with one another yet. To blend their insights and take a collective consensus, the concatenated matrix is multiplied by a final projection weight matrix $W_O$:

$$W_O \in \mathbb{R}^{8 \times 8}$$

$$\text{Final Output } Z = \text{Concat}(\dots) \times W_O$$

$$\underbrace{(5 \times 8)}_{\text{Concat}} \times \underbrace{(8 \times 8)}_{W_O} = \underbrace{\mathbf{5 \times 8}}_{\text{Final Contextual Representation}}$$

---

## Single-Head vs. Multi-Head: Direct Comparison

| Feature | Single-Head Attention | Multi-Head Attention ($H=4$) |
| --- | --- | --- |
| **Number of perspectives** | $1$ global view | $4$ distinct specialized views |
| **Projection weight shape** | $W_Q, W_K, W_V \in \mathbb{R}^{4 \times 8}$ | $4 \text{ sets of } W_Q^{(i)}, W_K^{(i)}, W_V^{(i)} \in \mathbb{R}^{4 \times 2}$ |
| **Attention map shape** | One $(5 \times 5)$ matrix | Four distinct $(5 \times 5)$ matrices |
| **Intermediate head output** | $5 \times 8$ | Four matrices of $5 \times 2$ |
| **Combination step** | None | Concatenate to $(5 \times 8) \to$ multiply by $W_O (8 \times 8)$ |
| **Final output shape** | $5 \times 8$ | **$5 \times 8$ (Identical)** |
| **Computational cost** | Proportional to $4 \times 8 = 32$ | Proportional to $4 \times (4 \times 2) = 32$ (Virtually identical) |

## Mental Model to Remember

```
Input Tokens X (5 x 4)
       │
       ├── Split into 4 parallel heads ───
       │         │           │           │
     Head 1    Head 2      Head 3      Head 4
     (5 x 2)   (5 x 2)     (5 x 2)     (5 x 2)
       │         │           │           │
       └── Concatenate columns together ──
                     │
              (5 x 8) Matrix
                     │
          Multiply by W_O (8 x 8)
                     │
              Final Representation (5 x 8)

```

The model gets **4 different lenses** to inspect the sentence simultaneously, splits the feature dimension so it doesn't get slower, and fuses the answers back together with $W_O$.

Here is the complete, runnable step-by-step implementation using NumPy, matching the dimensions ($N=5, D_1=4, D_2=8, H=4, D_3=2$):

```python
import numpy as np

# Set seed for reproducible numbers
np.random.seed(42)

# ==========================================
# 1. SETUP DIMENSIONS & INPUT
# ==========================================
N = 5        # Sequence length (number of tokens/words)
D1 = 4       # Initial embedding dimension per token
D2 = 8       # Desired model output dimension
H = 4        # Number of attention heads
D3 = D2 // H # Dimension per head: 8 // 4 = 2

# Simulated input matrix: 5 tokens, each 4-dimensional
X = np.random.uniform(-1, 1, size=(N, D1))
print("Input X shape:", X.shape)  # (5, 4)

# ==========================================
# 2. INITIALIZE LEARNABLE WEIGHTS
# ==========================================
# Each head i has its own W_Q, W_K, W_V matrices of shape (D1, D3) -> (4, 2)
W_Q = [np.random.uniform(-1, 1, size=(D1, D3)) for _ in range(H)]
W_K = [np.random.uniform(-1, 1, size=(D1, D3)) for _ in range(H)]
W_V = [np.random.uniform(-1, 1, size=(D1, D3)) for _ in range(H)]

# Final output projection weight W_O to blend all heads together
W_O = np.random.uniform(-1, 1, size=(D2, D2))  # (8, 8)

# ==========================================
# 3. COMPUTE ATTENTION PER HEAD (IN PARALLEL/LOOP)
# ==========================================
head_outputs = []

for i in range(H):
    # Step A: Project input X to head-specific Q, K, V
    # (5, 4) x (4, 2) -> (5, 2)
    Q_i = np.matmul(X, W_Q[i])
    K_i = np.matmul(X, W_K[i])
    V_i = np.matmul(X, W_V[i])
    
    # Step B: Raw attention scores (Q * K^T)
    # (5, 2) x (2, 5) -> (5, 5)
    scores = np.matmul(Q_i, K_i.T)
    
    # Step C: Row-wise Softmax (with max subtraction for numerical stability)
    exp_scores = np.exp(scores - np.max(scores, axis=-1, keepdims=True))
    A_i = exp_scores / np.sum(exp_scores, axis=-1, keepdims=True)  # (5, 5)
    
    # Step D: Weighted sum of values (A * V)
    # (5, 5) x (5, 2) -> (5, 2)
    head_i_out = np.matmul(A_i, V_i)
    
    head_outputs.append(head_i_out)
    print(f"Head {i+1} output shape: {head_i_out.shape}")

# ==========================================
# 4. CONCATENATION
# ==========================================
# Glue the four (5, 2) matrices side-by-side along axis=1 (columns)
# (5, 2) + (5, 2) + (5, 2) + (5, 2) -> (5, 8)
concat_heads = np.concatenate(head_outputs, axis=1)
print("\nShape after concatenation:", concat_heads.shape)  # (5, 8)

# ==========================================
# 5. FINAL LINEAR PROJECTION (W_O)
# ==========================================
# Blend the concatenated heads into the consensus representation
# (5, 8) x (8, 8) -> (5, 8)
final_output = np.matmul(concat_heads, W_O)

print("Final Output shape (Z):", final_output.shape)  # (5, 8)

```

### Output Summary

```text
Input X shape: (5, 4)
Head 1 output shape: (5, 2)
Head 2 output shape: (5, 2)
Head 3 output shape: (5, 2)
Head 4 output shape: (5, 2)

Shape after concatenation: (5, 8)
Final Output shape (Z): (5, 8)

```

### What Each Step Achieves:

1. **$X \to Q_i, K_i, V_i$**: Cuts the dimension from $4$ down to $2$ per head.
2. **$A_i \times V_i$**: Computes self-attention independently in its own $2$-dimensional subspace.
3. **`np.concatenate(..., axis=1)`**: Restores the target width back to $8$ ($4 \times 2 = 8$).
4. **`matmul(..., W_O)`**: Allows interaction between heads, creating the fused consensus representation of size $(5, 8)$.
