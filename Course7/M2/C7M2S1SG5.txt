In this implementation, the encoder still produces a sequence of hidden states, one for each input token. However, unlike the basic encoder–decoder model, the decoder no longer depends only on the final encoder state. 

 

At each decoding step: 

The current decoder hidden state is used to compute alignment scores with all encoder states. 

These scores are normalised to obtain attention weights. A context vector is computed as a weighted combination of encoder outputs. 

 

This context vector represents the part of the input sequence that is most relevant for predicting the current target word. 

 

The decoder now receives two sources of information at every time step: 

Its own internal state from previous predictions  

The context vector derived from attention over the input sequence 

 

By combining these, the decoder can shift its focus across different source tokens as translation progresses rather than treating the entire sentence as a single compressed signal. 

 

This behaviour reflects the conceptual working of attention discussed earlier but is now implemented within the training loop of a real neural network. 

 

Training still uses teacher forcing, where the correct target token is provided as the next decoder input during each step. However, the prediction at each time step now depends on the following: 

The evolving decoder state 

Dynamically computed context vectors from the encoder outputs 

 

Loss is accumulated across all decoding steps and backpropagated through the encoder, attention computation and decoder network. 

 

As training progresses, the model learns how to predict the next word and how to align segments of the input sentence with corresponding segments in the output sentence. 

 

During inference, the decoder again generates words one token at a time. At each step, attention weights are recomputed, allowing the model to refer back to different parts of the source sentence as needed. 

 

Compared with the basic encoder–decoder model, longer sentences are handled more effectively and important contextual information from earlier parts of the input is less likely to be lost. 

 

This behaviour is visible in the predicted translations, where phrase-level alignment is more consistent across longer sequences.
