The attention mechanism discussed earlier is fundamentally a series of these operations.


Consider an input sequence of length Equation, meaning there are Equation words. Each word is initially represented by a vector of dimension Equation, which is a basic, static representation. The objective is to transform these initial vectors into richer representations of dimension Equation​. 


This is achieved by constructing an input matrix Equation of size Equation​, where each row represents a word, and the columns represent the vector dimensions.


From this input matrix, three key matrices: Query (Q), Key (K), and Value (V), are derived using learnable parameters Equation​, Equation​, and Equation​, each of size Equation × Equation. These parameters are learned during training to optimise Q, K, and V. 


The Query matrix Q is obtained by multiplying Equation by Equation​, resulting in a matrix of size Equation​. The Key and Value matrices are similarly derived, each of size Equation.


The attention scores, which determine how much focus each word should have on others, are calculated by taking the dot product of the Query matrix Q and the transpose of the Key matrix K. Next, we created a sample input_matrix using a random number generator. This matrix represents the initial data points that we will work with in our attention mechanism. The code demonstrating this is mentioned below.

input_matrix = np.random.uniform(-1,1,size = (5,4))
 

Here, input_matrix is a 5x4 matrix, representing 5 examples, each with 4 features. These are the initial representations of our data points.


The next step involves initialising the weight matrices for the query (wQ), key (wK), and value (wV), which are essential for transforming the input data into the corresponding queries, keys, and values.

wQ = np.random.uniform(-1,1,size = (4,8)) #d_2 = 8
wK = np.random.uniform(-1,1,size = (4,8))
wV = np.random.uniform(-1,1,size = (4,8))
 

These matrices, randomly initialised to a size of 4x8, will convert the 4-dimensional input data into 8-dimensional queries, keys, and values.

 

Now, to calculate the queries (Q), keys (K), and values (V), matrix multiplication is performed between the input_matrix and the respective weight matrices.

Q = np.matmul(input_matrix,wQ) #X.W_Q
K = np.matmul(input_matrix,wK) #X.W_K
V = np.matmul(input_matrix,wV) #X.W_V
 

The resulting matrices Q, K, and V each have a shape of 5x8, which indicates that there are now 5 queries, 5 keys, and 5 values, each represented by an 8-dimensional vector.

 

The next operation involves computing the attention scores (QK) by multiplying the query matrix (Q) with the transpose of the key matrix (K).

QK = np.matmul(Q,K.T) #Q.K^T
 

This results in a 5x5 matrix, where each element represents the attention score between pairs of data points.

 

The attention scores (QK) are then normalised using the softmax function to ensure they sum up to 1 across each row. This normalisation is crucial for converting the scores into probabilities.

normalise_QK = []
for i in range(5):
    temp = [np.exp(QK[i,j])/sum(np.exp(QK[i])) for j in range(5)]
    normalise_QK.append(temp)
normalise_QK = np.array(normalise_QK)
 

The resulting matrix, normalise_QK, is a 5x5 matrix, where each row contains normalised attention weights.

 

Finally, the output representation is generated by multiplying the normalised attention weights with the value matrix V. This step combines the values in a weighted manner based on the normalised attention scores.

Attention = np.matmul(normalise_QK,V)
 

The resulting Attention matrix is a 5x8 matrix, which provides a richer representation of the original input data, reflecting the learned importance of each data point.

# Lecture Notes: Mathematics Behind Attention & Transformers

Transformers convert static input tokens into rich, context-aware representations entirely through matrix operations: linear projections, dot products, row-wise softmax normalization, and weighted value aggregation.

---

## 1. Core Intuition: The Q, K, V Triad

Before matrix algebra, each concept maps to an intuitive role in retrieval:

| Component | Intuition | Functional Role |
| --- | --- | --- |
| **Query ($Q$)** | *"What information am I looking for?"* | Search query posed by token $i$ |
| **Key ($K$)** | *"What information do I offer?"* | Matching key advertised by token $j$ |
| **Value ($V$)** | *"What content do I contribute?"* | Actual semantic payload delivered to the output |
| **Attention** | *"How much should token $i$ attend to token $j$?"* | Relevance score weighting the value vectors |

---

## 2. Input Sequence Representation

Given an input sequence of length $N$ tokens (e.g., `"Python program to print Hello world"`, where $N = 6$):

1. **Initial Vector Embedding:** Each token $i$ is converted into an initial embedding vector $x_i \in \mathbb{R}^{1 \times D_1}$, where $D_1$ is the input dimension.
2. **Input Matrix $X$:** Stacking all token vectors row-wise forms the input matrix:

$$X = \begin{bmatrix} — & x_1 & — \\ — & x_2 & — \\ & \vdots & \\ — & x_N & — \end{bmatrix} \in \mathbb{R}^{N \times D_1}$$

* **Rows ($N$):** Number of sequence tokens.
* **Columns ($D_1$):** Initial feature dimensionality per token.

---

## 3. Projection Matrices: Deriving $Q$, $K$, and $V$

Initial embeddings are static and lack sequence-aware context. The model projects $X$ into three distinct spaces using learnable parameter matrices:

* $W_Q \in \mathbb{R}^{D_1 \times D_2}$ (Query weights)
* $W_K \in \mathbb{R}^{D_1 \times D_2}$ (Key weights)
* $W_V \in \mathbb{R}^{D_1 \times D_2}$ (Value weights)

Where $D_2$ is the target model projection dimension.

### Linear Projections

$$Q = X W_Q \in \mathbb{R}^{N \times D_2}$$

$$K = X W_K \in \mathbb{R}^{N \times D_2}$$

$$V = X W_V \in \mathbb{R}^{N \times D_2}$$

### Dimensional Analysis

$$\underbrace{(N \times D_1)}_{X} \times \underbrace{(D_1 \times D_2)}_{W} = \underbrace{(N \times D_2)}_{\text{Projected Matrix}}$$

Every token now possesses an independent Query, Key, and Value vector of dimension $D_2$.

---

## 4. Computing the Attention Mechanism

### Step 1: Raw Attention Scores ($QK^T$)

The relevance (alignment) between every query $i$ and key $j$ is calculated via dot products across all tokens at once:

$$S = Q K^T \in \mathbb{R}^{N \times N}$$

$$\underbrace{(N \times D_2)}_{Q} \times \underbrace{(D_2 \times N)}_{K^T} = \underbrace{(N \times N)}_{S}$$

* $S_{i, j} = q_i \cdot k_j^T$ represents the unnormalized affinity score between token $i$ and token $j$.

### Step 2: Normalization via Softmax

To convert unconstrained real values into a valid probability distribution where weights along each row sum to $1$:

$$A = \text{softmax}(S) \in \mathbb{R}^{N \times N}$$

Row-wise formulation for token $i$ attending to token $j$:

$$A_{i, j} = \frac{\exp(S_{i, j})}{\sum_{k=1}^N \exp(S_{i, k})}, \quad \text{such that } \sum_{j=1}^N A_{i, j} = 1$$

* Exponentiation ($\exp$) ensures non-negativity ($\ge 0$).
* Denominator normalization guarantees all row elements sum strictly to $1$.

### Step 3: Weighted Sum of Values

The final output representation $Z$ (or $\text{Attention}$) is computed by taking a linear combination of all value vectors weighted by attention probabilities:

$$Z = A V = \text{softmax}(Q K^T) V \in \mathbb{R}^{N \times D_2}$$

$$\underbrace{(N \times N)}_{A} \times \underbrace{(N \times D_2)}_{V} = \underbrace{(N \times D_2)}_{Z}$$

Row $i$ of $Z$ is now a contextualized representation of token $i$, incorporating relevant signals from all $N$ tokens in the sequence.

---

## 5. End-to-End Dimension Pipeline

| Step | Operation | Input Shape | Transformation | Output Shape | Meaning |
| --- | --- | --- | --- | --- | --- |
| **1** | Token Embedding | Sequence of $N$ tokens | Lookup table | $X \in \mathbb{R}^{N \times D_1}$ | Static token vectors |
| **2** | Projection | $X$ | $\times W_Q, W_K, W_V$ | $Q, K, V \in \mathbb{R}^{N \times D_2}$ | Functional vectors |
| **3** | Alignment | $Q, K$ | $Q \times K^T$ | $S \in \mathbb{R}^{N \times N}$ | Raw pair-wise compatibility |
| **4** | Normalization | $S$ | Row-wise Softmax | $A \in \mathbb{R}^{N \times N}$ | Attention probability weights |
| **5** | Context Aggregation | $A, V$ | $A \times V$ | $Z \in \mathbb{R}^{N \times D_2}$ | Enriched contextual vectors |

---

## 6. Python Reference Implementation (NumPy)

```python
import numpy as np

# 1. Hyperparameters
N = 5   # Sequence length (tokens)
D1 = 4  # Initial embedding dimension
D2 = 8  # Projected representation dimension

# 2. Input matrix X (5 tokens x 4 features)
np.random.seed(42)
X = np.random.uniform(-1, 1, size=(N, D1))

# 3. Learnable projection weights
W_Q = np.random.uniform(-1, 1, size=(D1, D2))
W_K = np.random.uniform(-1, 1, size=(D1, D2))
W_V = np.random.uniform(-1, 1, size=(D1, D2))

# 4. Generate Queries, Keys, Values
Q = np.matmul(X, W_Q)  # Shape: (5, 8)
K = np.matmul(X, W_K)  # Shape: (5, 8)
V = np.matmul(X, W_V)  # Shape: (5, 8)

# 5. Raw alignment scores
QK_T = np.matmul(Q, K.T)  # Shape: (5, 5)

# 6. Row-wise Softmax normalization
# Vectorized implementation: subtract max along axis=-1 for numerical stability
exp_scores = np.exp(QK_T - np.max(QK_T, axis=-1, keepdims=True))
A = exp_scores / np.sum(exp_scores, axis=-1, keepdims=True)  # Shape: (5, 5)

# 7. Final contextual output
output = np.matmul(A, V)  # Shape: (5, 8)

print("Input shape: ", X.shape)
print("Attention weights shape: ", A.shape)
print("Enriched output shape: ", output.shape)
```
