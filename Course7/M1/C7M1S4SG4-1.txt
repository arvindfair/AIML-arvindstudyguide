# Dice Coefficient — understand it visually, step by step

The easiest way to understand the Dice coefficient is to imagine that a model draws a mask around an object, and we compare its drawing with the correct answer.

In image segmentation, the model predicts which pixels belong to an object, such as a tumor, a car, or a road. The Dice coefficient measures how much the predicted region overlaps with the actual region.

## 1. First, understand the two masks

Imagine we have a 4 × 4 image. Each cell represents one pixel.

- Ground truth: the correct mask prepared by a human or another trusted source.
- Prediction: the mask produced by our model.

Ground truth

Blue = object pixels

Model prediction

Red = predicted object pixels

In this illustration, four pixels overlap. The model correctly identifies four of the five actual object pixels, but it also predicts one extra pixel.

The important question is:

How much of the predicted object matches the actual object?

That is what Dice measures.

## 2. The Dice coefficient formula

\\[ \boxed{\text{Dice}=\frac{2|A\cap B|}{|A|+|B|}} \\]

Here:

- \\(A\\) = ground-truth object pixels.
- \\(B\\) = predicted object pixels.
- \\(|A|\\) = number of object pixels in the ground truth.
- \\(|B|\\) = number of object pixels predicted by the model.
- \\(|A\cap B|\\) = number of pixels shared by both masks.

In plain English:

\\[ \text{Dice}= \frac{2\times\text{overlapping pixels}} {\text{actual pixels}+\text{predicted pixels}} \\]

Why multiply the overlap by 2? Because the denominator counts the size of both masks. The multiplier makes the score reach 1 when the two masks match perfectly.

## 3. Calculate Dice using our example

From the two masks above:

| Measurement             | Count |
| ----------------------- | ----- |
| Actual object pixels    | 5     |
| Predicted object pixels | 5     |
| Overlapping pixels      | 4     |

Substitute into the formula:

\\[ \text{Dice}=\frac{2\times4}{5+5} \\]

\\[ =\frac{8}{10}=\boxed{0.8} \\]

So, our model gets a Dice score of 0.80, or 80%.

It is not simply the percentage of individual pixels classified correctly. It measures the overlap between the two object regions.

## 5. What is Dice loss?

During training, a model usually adjusts its weights to minimize a loss function.

But Dice is a score that we want to maximize. To turn it into a loss that we want to minimize, we use:

\\[ \boxed{\text{Dice Loss}=1-\text{Dice}} \\]

For our example:

\\[ \text{Dice Loss}=1-0.8=\boxed{0.2} \\]

Perfect segmentation: Dice = 1, Dice loss = 0.

No overlap: Dice = 0, Dice loss = 1, assuming a nonempty target and prediction.

As training improves the predicted mask, its overlap with the ground truth should increase. The Dice score rises, and the Dice loss falls.

## 6. Dice coefficient vs. Intersection over Union (IoU)

Your course says Dice is similar to IoU. Both measure overlap, but their formulas differ.

\\[ \text{IoU}=\frac{|A\cap B|}{|A\cup B|} \\]

Here, the union means all pixels belonging to either mask, counting shared pixels only once.

Using our example:

- Actual pixels = 5
- Predicted pixels = 5
- Shared pixels = 4
- Union pixels = \\(5+5-4=6\\)

Therefore:

\\[ \text{IoU}=\frac{4}{6}\approx0.667 \\]

\\[ \text{Dice}=\frac{8}{10}=0.8 \\]

| Metric | Formula         | Example score |
| ------ | --------------- | ------------- |
| Dice   | \\(2I/(A+B)\\)  | 0.800         |
| IoU    | \\(I/(A+B-I)\\) | 0.667         |

For the same masks, Dice is numerically higher than IoU. They are related by:

\\[ \text{Dice}=\frac{2\text{IoU}}{1+\text{IoU}} \\]

Don't compare their numerical scores as if they were the same metric.

## 7. Why is Dice useful when classes are imbalanced?

Imagine an image containing 10,000 pixels:

- 9,900 pixels are background.
- Only 100 pixels belong to a small tumor.

A model that predicts every pixel as background gets 99% pixel accuracy, but completely misses the tumor.

Pixel accuracy can be misleading

# 99%

Pixel accuracy

# 0

Tumor pixels detected

The model looks accurate because background dominates the image, but it fails at the task that matters.

Pixel-wise cross-entropy evaluates each pixel's class prediction individually. With class imbalance, the abundant background can dominate the aggregate training signal.

Dice directly measures overlap between the target object and the predicted object. This makes it particularly useful for segmentation tasks involving small or underrepresented regions.

Important: Dice does not automatically solve every class-imbalance problem. In practice, models may combine Dice loss with cross-entropy, use class-specific Dice scores, or apply class weighting.

## 8. One more important concept: Soft Dice

Your video also describes a prediction matrix where values are probabilities, rather than just zeros and ones.

This is important because neural networks typically produce probabilities before the final segmentation mask is created.

Suppose the ground truth is:

\\[ A=[1,1,0,0] \\]

And the model predicts:

\\[ B=[0.9,0.8,0.2,0.1] \\]

The ground truth uses:

- `1` = object pixel
- `0` = background pixel

The model's values represent its confidence that each pixel belongs to the object.

For this example:

\\[ \sum A=2,\qquad \sum B=2.0 \\]

The overlap term is calculated by multiplying corresponding elements and adding the results:

\\[ \begin{aligned} \sum(A_iB_i) &=(1)(0.9)+(1)(0.8)\\\ &\quad +(0)(0.2)+(0)(0.1)\\\ &=1.7 \end{aligned} \\]

Therefore:

\\[ \text{Soft Dice}=\frac{2(1.7)}{2+2} =\boxed{0.85} \\]

Soft Dice rewards high probabilities on actual object pixels and penalizes probability assigned to the object where the target is background.

This is the same general idea as binary Dice, but it uses continuous prediction values instead of first converting every prediction into a hard 0 or 1. Some implementations add a small smoothing constant to the numerator and denominator to avoid division by zero.

### Final summary

- Dice coefficient: measures overlap between the actual mask and predicted mask.
- Dice loss: \\(1-\text{Dice}\\), used to train the model by minimizing the loss.
- IoU: another overlap metric, with a different formula.
- Soft Dice: calculates overlap using prediction probabilities, allowing the loss to be differentiable during training.
- Class imbalance: Dice can be more useful than pixel accuracy when the object occupies only a small part of the image.

The one thing to remember is: Dice asks how well the predicted object region overlaps the real object region.
