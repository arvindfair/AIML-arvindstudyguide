An effective embedding space has useful structural properties. Small changes in the input lead to small changes in the embedding, creating a smooth and continuous space. This makes embeddings useful not just for prediction, but also for ranking, clustering, retrieval, and similarity search. 

 

In practice, convolutional neural networks act as encoders that perform this transformation. In summary, we learnt that features are the abstract patterns a network has learned to recognise, such as edges, textures, or object parts. Activations are the numerical responses of neurons indicating how strongly those features are present in a given input. An embedding, on the other hand, is a compact, fixed-length vector that summarises the overall content of the input by combining many such activations into a single representation. 

 

However, these embeddings intentionally discard spatial structure. They capture what is present in an image, but not where it appears. This is sufficient for tasks like classification, but it becomes limiting when the output itself must be structured or spatially aligned with the input.

# Complete lesson: Embedding vectors

## 1. Image as a tensor — the mathematical foundation

A computer represents an image as a tensor: an organized collection of numerical values.

For a color image, its shape is commonly:

\\[ \text{Image}\in\mathbb{R}^{H\times W\times C} \\]

- \\(H\\) = height in pixels
- \\(W\\) = width in pixels
- \\(C\\) = number of color channels, usually 3 for RGB

For example, a \\(2\times2\\) RGB image contains \\(2\times2\times3=12\\) numerical values.

### Visualizing an RGB image

## R

## G

Green channel

[0, 255]

[0, 255]

## B

Blue channel

[0, 0]

[255, 255]

Each channel has its own 2 × 2 grid. Together they describe the four RGB pixels. The numbers here are illustrative.

A typical 4K RGB image contains approximately \\(3840\times2160\times3=24.9\\) million channel values.

That is a lot of numbers to process. Also, the numbers describe colors and positions, not necessarily the semantic meaning of the scene.

## 2. Pixel space vs representation space

These are two different ways to describe an image.

### Pixel space

Describes the image using its original pixel values.

Image A: [12, 80, 190, 45, 90, ...] Image B: [18, 74, 185, 51, 86, ...]

A small shift, lighting change, or pose change may alter many values.

### Representation space

Describes an image using learned, meaningful patterns.

Conceptual illustration of learned clusters

The objective is to learn a transformation that makes useful semantic relationships easier to measure.

## 3. Embedding as a mathematical function

The notes describe an embedding as a mapping from a high-dimensional input into a lower-dimensional vector space.

We can write:

\\[ f:X\rightarrow Z \\]

Here:

- \\(X\\) is the input space, such as image tensors.
- \\(f\\) is the learned encoder or embedding function.
- \\(Z\\) is the representation space.
- \\(z=f(x)\\) is the embedding of input image \\(x\\).

For example:

\\[ \underbrace{x\in\mathbb{R}^{224\times224\times3}}\_{\text{150,528 values}} \xrightarrow{\ f\ } \underbrace{z\in\mathbb{R}^{512}}\_{\text{512 values}} \\]

This is an illustrative dimensionality example, not a requirement for every model.

The crucial distinction is that an embedding isn't simply any compressed file. It is a learned, task-informed representation intended to preserve information useful for the model's objective.

## 4. Why not use one-hot encoding?

One-hot encoding represents each category with a vector containing one `1` and otherwise `0`s.

Suppose we have three categories: cat, dog, and toaster.

| Category | One-hot vector |
| -------- | -------------- |
| Cat      | `[1, 0, 0]`    |
| Dog      | `[0, 1, 0]`    |
| Toaster  | `[0, 0, 1]`    |

This method is useful for representing category identities, but it doesn't inherently encode semantic similarity.

The Euclidean distance between these one-hot vectors is \\(\sqrt{2}\\).

The same distance occurs between cat and toaster. The encoding alone doesn't know that cats and dogs are more alike.

Learned embeddings can instead place cats and dogs closer together if the training objective teaches the model that they are semantically related.

Remember: one-hot encoding identifies a category; a learned embedding can represent relationships between categories.

## 5. How a CNN learns representations

A convolutional neural network doesn't usually recognize an entire object in one step. It builds representations through successive layers.

Input image

Raw pixels

Early layers

Edges, lines, color changes

Intermediate layers

Textures, curves, repeated patterns

Deeper layers

Object parts and more abstract patterns

Embedding

Compact representation combining learned information

These are typical tendencies, not rigid rules. The exact patterns depend on the architecture, data, and training objective.

### What is a filter?

A convolutional filter is a small set of learned weights that slides across an input feature map. It responds to local patterns.

For example, an edge detector may respond strongly where pixel intensity changes sharply.

A simplified view:

### Input

A simple light-to-dark boundary

### Filter response

Strong response near the edge

The filter weights define what pattern a filter responds to; the activation tells us how strongly it responds at a particular location. In a trained CNN, these weights are generally learned rather than manually programmed.

## 6. Encoder and latent space

An encoder is the part of a model that converts the input into a learned representation. In your notes, CNN layers are given as an example of an encoder.

A latent space is the learned space containing these hidden representations.

Input image \\(x\\)

Encoder \\(f\\)

Latent representation \\(z=f(x)\\)

A point or vector in the learned space

The model learns its representation during training. Ideally, meaningful relationships in the original data become easier to recognize in latent space.

Distance and direction may reflect semantic relationships, but they don't automatically have a universal meaning: that depends on the model and how it was trained.

## 7. The four properties of a useful embedding space

| Property               | Meaning                                                        | Example                                                 |
| ---------------------- | -------------------------------------------------------------- | ------------------------------------------------------- |
| Semantic similarity    | Similar meanings have nearby representations                   | Different dog breeds                                    |
| Continuity             | Small input changes often produce small representation changes | Slight lighting variation                               |
| Clustering             | Related examples form groups                                   | Cats grouped separately from cars                       |
| Dimensional efficiency | Useful information is represented compactly                    | Hundreds of numbers instead of millions of pixel values |

One subtle point: clustering without labels is not guaranteed just because embeddings exist. The model's training process must learn a representation that supports the desired grouping.

| Activation | The numerical response to a pattern         | How strongly the detector responds |
| Embedding  | A compact representation of the whole input | A summary of the image             |

These terms are related, but they are not interchangeable.

A CNN layer can produce a large activation tensor containing responses at many spatial positions. A later operation may combine that information into a single fixed-length embedding.

## 10. Why do we need an encoder–decoder architecture?

An encoder compresses an input into a representation. But sometimes we need to produce an output that looks like an image, not just a category or vector.

Examples include:

- Reconstructing an image.
- Removing noise from an image.
- Generating an image.
- Segmenting an image into different regions.

An encoder–decoder architecture combines two parts:

Input image

### Encoder

Extracts features and reduces spatial resolution

### Bottleneck

Compact, information-rich representation

### Decoder

Transforms the representation into a desired output

Output image or spatial prediction

Think of it this way:

- The encoder asks, "What useful information can I extract?"
- The bottleneck holds a compressed representation.
- The decoder asks, "How can I turn this information into the output I need?"

Not every decoder reconstructs a realistic image. Its output depends on the task and training objective.

## 11. What is a bottleneck?

A bottleneck is the narrowest or most compressed stage of a network's representation.

Imagine compressing a large image into a smaller representation.

Large feature maps

64 × 64 × 64

Smaller feature maps

16 × 16 × 128

Bottleneck

4 × 4 × 256

Illustrative feature-map dimensions, not a prescribed architecture.

Notice something important: the height and width decrease, while the number of channels can increase. Therefore, a bottleneck does not necessarily contain fewer total numbers at every stage. It is the compressed spatial representation that matters here.

The bottleneck is designed to capture useful higher-level information. Excessive compression, however, can cause the model to lose details.

## 12. What is reconstruction?

Reconstruction means producing an approximation of an original input from a learned representation.

A classic example is an autoencoder.

Original image \\(x\\)

Encoder

Latent code \\(z\\)

Decoder

Reconstructed image \\(\hat{x}\\)

The model tries to make the reconstruction resemble the original image.

A simple pixel-based reconstruction loss is:

\\[ L=\frac{1}{N}\sum\_{i=1}^{N}(x_i-\hat{x}\_i)^2 \\]

Here, \\(x_i\\) is an original pixel value and \\(\hat{x}\_i\\) is its reconstructed value. The model learns to reduce the average squared difference.

This is one possible loss function, not the only one. Depending on the task, reconstruction may use other objectives.

## 13. What is U-Net, and why is it special?

U-Net is an encoder–decoder architecture widely used for image segmentation and other tasks requiring spatially aligned outputs.

Its special feature is skip connections: they transfer features from the encoder to corresponding stages of the decoder.

## U-Net architecture

Simplified conceptual diagram

Schematic only; actual U-Net has multiple convolutional blocks and paired skip connections.

### Why are skip connections necessary?

The encoder learns high-level information, but downsampling can lose precise location and boundary details.

The decoder upsamples its feature maps to produce a spatial output. Skip connections give it access to earlier, higher-resolution features.

Think of it as combining two kinds of knowledge:

- Deep features: what the object is.
- Shallow features: fine details about where its edges and boundaries are.

Together, these can improve pixel-level predictions.

Encoder-Decoder Architecture

Some vision tasks require more than a single label or scalar output. In problems such as image segmentation, depth estimation, and image reconstruction, the model must produce dense, spatially aligned predictions. In these settings, a prediction is required for every pixel rather than for the image as a whole.  

 

Standard convolutional neural networks designed for classification rely heavily on pooling operations, which discard spatial detail in order to improve invariance and robustness. While effective for recognition tasks, this loss of spatial information makes such architectures unsuitable when the output itself needs structure.
