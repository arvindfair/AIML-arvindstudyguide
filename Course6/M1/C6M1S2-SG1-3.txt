SVM and Kernals 

Session Overview


Welcome to the session on ‘Kernels’. 

 

Kernels represent one of the most innovative ideas in machine learning, born from mathematical insight and widely adopted for their ability to handle complex, nonlinear data. This session focuses on developing a strong intuition for what kernels are and why they are so powerful. 

 

We will begin by examining the limitations of linear feature spaces when faced with nonlinear relationships. From there, you will explore how kernels provide an elegant solution by enabling models to operate in higher-dimensional spaces without explicitly computing those transformations, significantly reducing computational effort. The central concept you will encounter is the kernel trick, which allows SVMs to achieve nonlinear separability while preserving efficiency. We will also discuss the different types of kernels, that can be used on different types of input data.

 

Finally, you will apply these ideas in practice through a demonstration on letter recognition, observing how kernel-based models extend decision boundaries far beyond the linear case.

The Kernel Trick
----------------


In the previous lectures, you learnt how to transform a nonlinear data set into a linear one. You also saw that there is an exponential increase in the number of dimensions when you transform the attribute space to a feature space. This makes the modelling (i.e. the learning process) computationally expensive.

 

Now, let's see how you can solve this problem using kernels. 

 

Think of a kernel as a black box, as shown in the figure below. The original attributes are passed into the black box, and it returns the transformed attributes (in a higher-dimensional feature space). The SVM algorithm is shown only the transformed, linear feature space, where it builds the linear classifier as usual.  

 

However, what makes kernels special is that they don't do this transformation explicitly (which is a computationally difficult task, as we discussed), but they use a mathematical hack to do this implicitly.

Pre-reading - Inner Product

 

In the coming lectures, you will need to recall the concept of the inner product (or dot product) of two vectors. Say there are two vectors A = [2, 3, 5] and B = [1, 0, 4], then the dot product (or the inner product) of A and B is the element-wise multiplication of A and B, i.e. transpose(A). B = A'B = 2.1 + 3.0 + 5.4 = 22. 

 

Note that the inner product of two vectors returns a scalar number, in this case 22.

 

Similarly, in any given dataset with n attributes, you can think of each data point (i.e. each row) as a vector of length n. Thus, the dot product of two rows, or observations, will return a scalar value. This concept will be helpful in the following video.

Perform computationally heavy transformations 
 

In practice, you only need to know that kernels are functions which help you transform nonlinear datasets. Given a dataset, you can try various kernels and choose the one that produces the best model. The three most popular types of kernel functions are: 
 

The linear kernel: This is the same as the support vector classifier, or the hyperplane, without any transformation at all
 
The polynomial kernel: It is capable of creating nonlinear, polynomial decision boundaries 
 
The radial basis function (RBF) kernel: This is the most complex one, which is capable of transforming highly nonlinear feature spaces to linear ones. It is even capable of creating elliptical (i.e. enclosed) decision boundaries
