Minority Class Problem

This is known as ‘class imbalance’ or a minority class problem.


There is a disparity between the two class labels in the data set with which we are working. The records of one class label are highly imbalanced with respect to those of the other class. An imbalanced class leads to biased predictions and misleading accuracies. When the majority class dominates over the minority class, the machine learning algorithm tries to learn the majority class better and fails to predict the minority class. The algorithm becomes incapable of identifying the minority class while making predictions. This results in misleading accuracy. As the model is predicting the majority class well, naturally, the accuracy score will be higher, and it will not capture the inefficiency of the model in predicting the minority class.

 

So, there are different techniques of handling class imbalance, which are as follows:

Random undersampling
Random oversampling
Synthetic minority oversampling technique (SMOTE)
Adaptive synthetic sampling method (ADASYN)
SMOTETomek (Oversampling followed by undersampling)
 

In the upcoming videos, you will learn about each of these techniques in detail.

 

One key point to remember here is that always apply these resampling techniques on the train set, not on the test set. Applying them to the test set will lead to data leakage, and the model will remember the instances of the test set. Note that the true test is always on the unseen data. Hence, there will not be any unseen data left to test the model performance on. So, always remember to do the train-test split before applying class imbalance techniques.
